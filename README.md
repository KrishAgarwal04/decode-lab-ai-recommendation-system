**Project Title**  
**AI Recommendation System**


**Description :**  
A simple recommendation system that suggests items based on user preferences. It collects user interests, matches them using predefined logic, and displays personalized recommendations.

**Features :**  
Accepts user preferences  
Matches interests using rule-based logic  
Generates personalized recommendations  
Fast and easy to use  
Beginner-friendly implementation  


**Technologies Used**  
Python


**How to Run :**  
git clone https://github.com/your-username/ai-recommendation-system.git  
cd ai-recommendation-system  
python main.py
